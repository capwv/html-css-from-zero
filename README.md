# HTML و CSS من الصفر

أكاديمية تفاعلية بالعربي (عامية مصرية) لتعلم HTML و CSS من الصفر تماماً، جزء من منصة أكاديميات Infinity University Activity.

**الموقع المباشر:** https://capwv.github.io/html-css-from-zero/

## المحتوى

- **14 درس متدرج** (13 درس + مشروع ختامي): من "الويب بيشتغل إزاي؟" لحد نشر أول صفحة على GitHub Pages
- **51 سؤال تفاعلي** بتصحيح فوري وشرح لكل إجابة
- **28 تمرين عملي** بمحاولات وكشف حل نموذجي
- **معمل HTML و CSS تفاعلي** داخل المتصفح: محرر لايف بمعاينة فورية (iframe) + **13 تحدي موجه** بتتصحح تلقائياً بتحليل الكود اللي بتكتبه، من أول `<h1>` لحد `@media` query
- تتبع تقدم محلي (localStorage) لكل درس وسؤال وتمرين وتحدي

## الدروس

1. الويب بيشتغل إزاي؟
2. أول صفحة HTML
3. الـ Tags والبنية
4. النصوص واللينكات
5. الصور
6. القوائم والجداول
7. الفورم
8. الـ Semantic HTML
9. الـ CSS Selectors
10. الألوان والخطوط
11. الـ Box Model
12. Flexbox
13. الـ Responsive Design
14. المشروع الختامي: انشر أول صفحة ليك على GitHub Pages

## التقنية

صفحة واحدة (index.html) بدون أي build: HTML + CSS + JavaScript خام، محرر ومدقق المعمل مكتوبين بالكامل بـ JavaScript (lab-core.js + lab.js)، خلفية متحركة مشتركة (sams-bg.js)، وتصميم داكن متجاوب مع الموبايل.

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح، أو:

```bash
python -m http.server 8000
```
